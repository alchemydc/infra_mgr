# Project Brief

## Overview
A set of tools to manage provisioning, configuration, instrumentation and destruction of infrastructure.

## Core Features
- Quick and easy provisioning of infrastructure within GCP
- Quick and easy configuration of infrastructure
- Secure but usable secrets management
- Lightweight monitoring of infrastructure
- Semi-automated cost monitoring and containment
- Security built-in, not bolted on

## Target Users
DevOps personnel

## Technical Preferences
- Terraform for IAC provisioning, specifically leveraging the [Cloud Foundation Fabric](https://github.com/ZcashFoundation/cloud-foundation-fabric)
- Ansible for IAC configuration management
- Stackdriver for monitoring
